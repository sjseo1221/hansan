## 주의

- **추가 인기도 신호**: 유튜브 Data API 는 검색이 하루 100회(전 장소 37일)라 30일 갱신 의무를 지킬 수 없고, 수치로 점수·비율을 만드는 것이 금지(Developer Policies III.E.4.h)라 쓰지 않았다. 대신 관광공사 중심 관광지(티맵 내비 기반) 순위를 인기도에 20% 반영한다.

- **경기 유동인구**: 4유형(변경금지·상업적 이용금지). 발주자가 개인용 비상업 서비스로 보고 사용을 결정했다(2026-10-12). 화면에 "출처: 경기도" 를 표시한다.
- **서울 인증키**: 약관 제7조①은 키 공개·공유를 금지한다. GitHub Secrets 에만 둔다. 활용사례가 없으면 키 사용이 제한될 수 있고(제6조④), 등록에는 실제 서비스 주소가 필요하다(GitHub 주소 불가) — 3단계 화면 공개 후 등록.
- **TourAPI 공용 한도**: KorService2 의 여러 기능이 하루 1,000건을 함께 쓰는 것으로 보인다. 2026-10-12 수동 재실행으로 1,000건을 넘기자 운영 정보 수집이 실패했다. 평소 하루 최대 사용은 900건 이하다.
- **NAVER**: 2026-10-07 시행 약관 개정분은 확인하지 못했다. 원문 게시물은 저장하지 않는다.
