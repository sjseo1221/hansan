## 비용·상한 (NFR-COST-01~04)

- 운영 비용: Cloudflare Workers 무료 플랜(정적 자산·Durable Object SQLite), GitHub 공개 저장소 Actions(표준 러너 무료), 공공 API·네이버 무료 한도. OpenAI 외 과금 없음.
- 상한: 출처별 하루 상한이 제공처 무료 한도 안인지 시험(`config/sources.yaml freeLimits`, `pipeline/test/config.test.ts`). 주간 리포트가 실제 사용량 80% 경고.
- OpenAI: 생성 월 $5 + 대화 차단선 $15 = 월 예산 $20(시험 고정). 대화가 닫혀도 피드·상세는 정적 파일이라 그대로 동작.

## 주간 품질 리포트 (FR-OPS-02·03·08)

- `compute-daily` 가 지난주 리포트가 없으면 만든다 → `docs/reports/weekly/<주>.md`, `data/reports/weekly/<주>.json`. 첫 리포트는 2026-10-19(월) 실행분(2026-W42).
- 적중률은 서울 실측이 있는 장소(32곳)만 평가할 수 있어 표본이 작다. 실측 없는 건수를 함께 적는다.
