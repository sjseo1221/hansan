## 1. 결론

수집 체계는 모두 만들어 가동 중이다. 2026-10-12 낮에 전체 수집을 한 번 더 돌린 결과, 다섯 작업 중 넷이 성공했다. 운영 정보 하나는 같은 날 수동 재실행이 겹쳐 제공처 하루 한도를 넘겨 실패했다(아래 3절).

완료 기준 "모든 출처 자동 수집 3일 연속 성공"은 아직 판정할 수 없다. 자동 예약은 2026-10-12 새벽부터 돌기 시작했고(보조 출처는 10-12 밤부터), 3일째 판정일은 **2026-10-15**다.

경기 유동인구 자료(공공누리 4유형)는 발주자가 개인용 비상업 서비스로 보고 사용을 결정했다(2026-10-12, 4절).

## 3. 운영 중 확인된 문제와 조치

- **GitHub 예약 실행 누락**: 서울 매시간 작업이 3시간 동안 0회 실행됐다. Cloudflare Cron Trigger 가 워크플로를 직접 실행하도록 바꿨다(Worker `hansan-cron`). 실패하면 한 번 더 시도한다.
- **TourAPI 연결 실패**: 특정 GitHub 러너에서 연결이 일시적으로 실패했다. 연결 실패 시 한 번 더 시도하고 원인 코드를 기록한다.
- **TourAPI 하루 한도**: KorService2 여러 기능이 하루 1,000건을 함께 쓰는 것으로 보인다. 평소 최대 사용은 900건으로 맞췄다. 10-12 수동 재실행으로 넘기자 운영 정보가 실패했다. 오류 사유 코드를 기록하도록 고쳤다(22 = 한도 초과).
- **좌표 0 문제**: 좌표가 빈 후보가 (0, 0)이 되어 날씨 격자가 바다로 가던 문제를 막았다. TourAPI 좌표 자체가 국외(117.99, 19.69)인 15곳은 제외했다.
- **오매칭**: 동구 ⊂ 남동구, 백덕산(평창) ↔ 백덕산(영월) 같은 오매칭을 규칙과 시험으로 막았다.

리뷰: claude-reviewer 와 review-expert 가 두 차례 독립 리뷰했다(2차: Critical 1 · Major 13). 모두 반영했다. 자동 시험 68개가 push 마다 실행된다.

1. **경기 유동인구(FR-DATA-05)**: 공공누리 4유형이나 발주자 결정으로 사용한다(개인용 · 비상업). 화면에 "출처: 경기도" 표시.
2. **화면 출처 표시**(3단계 반영): 서울 "서울특별시 공공데이터", 기상청 "출처: 기상청", 경기 "출처: 경기도" 표시가 필수다.
3. **서울 활용사례 등록**: 실제 서비스 주소가 있어야 등록할 수 있어 3단계 화면 공개 후 등록한다(착수 계획 2.2절).
